Reference fidelity notes

Preserved

  • Project-switching sidebar with user identity, grouped projects, add action, and keyboard search.
  • Substantial illustrated cover, quiet project metadata, paired header actions, and underlined destination tabs.
  • Narrative main column paired with a compact contextual rail, fine dividers, restrained cards, and low elevation.
  • Intrinsic control proportions, compact chips, calm spacing, and purposeful continuity cues.

Intentionally dropped or changed

  • The freeform atmosphere and lettering controls were removed: MVP themes are curated presets and project themes cannot change typography.
  • “Settled without you” was replaced with recap and pending review: agent output cannot silently enter Canonical State.
  • The reference’s generic “Do this next” became the Canonical-State-bound AI recommendation in “What’s up next.”
  • External font requests and JavaScript interactions were removed so this comparison is fully offline; native system typography and static state variants are shown instead.
  • Topics and Project Map were added to persistent navigation because both are required MVP destinations.
