# Reconciliation — Pile Cover Handoff

**Input:** [`imports/pile-cover-handoff.md`](imports/pile-cover-handoff.md)  
**Compared with:** [`DESIGN.md`](DESIGN.md), [`EXPERIENCE.md`](EXPERIENCE.md), and the complete `.memlog.md` through finalization  
**Authority rule:** the current spines and later memlog decisions win on conflict.

## Result

The central qualitative idea is preserved: every project receives one automatic, deterministic, on-device, data-bound vector pile in Project Library and Overview. It depicts no subject, uses project theme tokens, remains meaningful offline, exposes generated text equivalents, and has no decorative or AI-generated path. Later decisions intentionally refine proposal counting, remove milestone capstones and custom photos, retain superseded Decisions, and make internal marks non-interactive.

All implementation-shaping questions raised by the import are closed in the final contract. Mark size is provenance- and duration-neutral; placement and append-only relative stability are deterministic; the renderer must support at least 40 Decisions; accepted agent proposals and direct user Decisions have equal visual authority; and the full renderer is limited to Project Library and Overview for MVP.

## Closure decisions

1. **Duration semantics:** rejected for mark sizing; consistent type-specific dimensions are canonical.
2. **Stable identity:** hard relative stability is canonical, with only uniform whole-composition scaling allowed.
3. **Exact geometry and density:** right-side Questions, centered proposal-set marks, deterministic first-fit Decisions, and the 40-Decision floor are committed.
4. **Provenance:** the cover is provenance-neutral; details remain available in inspectors, history, and Project Map.
5. **Additional placements:** Library and Overview only for MVP; export regenerates from data; share/print are deferred.
